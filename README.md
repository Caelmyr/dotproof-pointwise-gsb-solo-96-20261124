# DotProof · 压点校样台

DotProof 对平整凸点压样的单张定向侧光照片逐点核对纸上印位。它读取原片坐标和操作者的现场复核，封存可以重复打开的压样复核单。

## 启动

运行 `./start.sh`，打开 [本地工作台](http://127.0.0.1:19899/)。
`DOTPROOF_PORT` 更改回环端口，`./start.sh stop` 停容器并保留命名卷。
已安装锁定依赖时可另用 `python -B -m dotproof`，默认监听 8000。

## 核对压样

1. 导入单帧 PNG、JPEG 或 TIFF，或打开标明为合成的三行练习压样。
2. 在原片标出第一格左上点与基线方向点，填写两点间的实际距离。按纸上间距填点距、格距和行距。字模每行用空格分格，每格填实际应压的点号，空格位填 `-`。
3. 预览读数，再应用版位。按「原片」和「点阵」对照。点按原片格点或选异常，记录结论、备注和原片证据位置。改动几何时可以先封存当前复核单。
4. 平移起点或方向点重取同一张原片时，预览会按每条复核留档的原片证据位置，找新格点里取样完整的凸点：落在一个取样半径内、实际读到凸点的格点才接续，每条只接一格、每格只收一条。两条都靠近同一格而其中一条另有合格格点时，两条各接到一格；确实争抢同一格时取证据更近的一条，距离相当时保留已确认的结论。应用后接上的复核沿用原结论与备注，接不上的留在现行复核的「未接续的原片证据」里，可点回原片位置继续处理，不会当成新格点的结论。预览阶段不改现行版位和复核，已封存的复核单保持原样。
5. 封存复核单，重开后下载原坐标标记 PNG 或点位 CSV。来源 PNG 始终以相同的显示坐标提供。
6. 「照片准备」可单独检查清晰度、裁剪、配准和曝光。准备结果可作为一张新压样导入，旧原片仍可打开。

上限为 12 MiB、320 万像素、12 行，每行 24 格。使用 EXIF 方向转换后的 RGB 检查坐标。判读以照明从左来的局部明暗差作候选，根据取样是否超出画面区分「未入画」。现场歧义用原片和人工备注复核。工具用于平面压样的图像检查，未测量点高或进行语义翻译。
